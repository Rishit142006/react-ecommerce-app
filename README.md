# react-ecommerce-app
React-based e-commerce frontend with product listing, cart, and checkout using React Router, Axios, and Context API.


## Features
- Product Listing (API)
- Product Detail Page
- Cart Management (Context API)
- Checkout Page
- React Router Navigation

## Tech Stack
- React
- Axios
- Context API
- React Router

## How to Run
npm install
npm start
